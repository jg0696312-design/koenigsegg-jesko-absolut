# Koenigsegg Jesko Absolut

Przejrzysta, responsywna strona informacyjna o hipersamochodzie Jesko Absolut — jego aerodynamice, silniku i osiągach.

**[Otwórz stronę internetową](https://jg0696312-design.github.io/koenigsegg-jesko-absolut/)**

## Na stronie

- Najważniejsze dane techniczne w czytelnym układzie
- Opis aerodynamiki i koncepcji modelu
- Informacje o silniku V8 i skrzyni Light Speed Transmission
- Galeria zdjęć
- Widok dopasowany do telefonów i komputerów

## Pliki

- [`index.html`](./index.html) — cała strona wraz ze stylami
- Witryna jest publikowana przez GitHub Pages z głównej gałęzi repozytorium

Dane techniczne mają charakter informacyjny i mogą zależeć od paliwa, konfiguracji oraz warunków testowych.
